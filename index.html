자료와 확인 기준

제공된 인수인계 자료 6건을 요약했습니다. 문서의 과거 사례 날짜는 반복 일정으로 사용하지 않았습니다. 비밀번호, 계좌번호, 개인 연락처와 상세 경영정보는 포함하지 않았습니다.

월 중 업무는 예상 소요일을 반영한 ‘초안’으로 달력에 배치합니다. 원문에 없는 기간은 업무 계획을 위한 추정이며 법정 기한이 아닙니다. 원문의 전자투표 D+10 표기는 같은 문서의 상세 안내에 따라 D−10으로 정리했습니다.

계정과 저장

로그인하면 같은 계정으로 어느 기기에서든 일정을 이어서 관리할 수 있습니다.

12자 이상의 비밀번호를 사용하세요. 이메일 인증 → 로그인 → 관리자 승인 후 본인만 이용하는 캘린더가 열립니다. 기존 재무 앱의 계정과는 별개입니다.

가입·승인 메일 연결을 준비 중입니다. 자동 발송 설정이 끝나면 가입 신청을 열 수 있습니다.

DB에 자동 저장개인 일정·완료 상태·기준일은 Supabase DB에 계정별로 저장합니다. 사이트를 닫거나 브라우저 데이터를 지워도 DB에 저장된 내용은 유지됩니다. GitHub Pages는 화면 파일을 제공합니다.

저장 상태 확인‘DB에 저장됨’을 확인한 뒤 닫아 주세요. 연결이 끊기면 미저장 상태를 표시합니다. 로그인 유지를 위한 세션 정보만 브라우저에 보관합니다.

기존 데이터가 있으면 로그인 후 옮길 수 있습니다. 같은 업무의 값은 기존 브라우저 값을 적용합니다. 원본은 지우지 않습니다.
